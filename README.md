# 오피스톡 (가칭)

작은 회사 구성원이 주제별 채널에서 대화하고, 놓친 대화를 다시 찾는 **사내 메신저**입니다.
Slack 의 채널·스레드 흐름에 카카오톡식 읽음 표시를 더하고, AI 가 밀린 대화를 요약하고 할 일을 뽑아 줍니다.

> 바이브코딩 해커톤(2026-09-28 ~ 10-02) 과제 "사내 채팅어플 만들기" 결과물입니다.

## 데모

- 배포 URL: https://office-chat-two.vercel.app (2026-09-30 대시보드·화면 개편 배포)
- 시연 계정: 제출 시 별도 전달

## 주요 기능

| 분류 | 기능 |
|---|---|
| 기본 대화 | 채널 실시간 채팅, 공개·비공개 채널, 1:1 DM, 파일·이미지 첨부 |
| 놓치지 않기 | 대화별 미읽음 수, 메시지별 **안 읽은 사람 수**, **알림** — DM·@멘션·스레드 답글이 오면 화면 안 알림, 다른 탭을 보고 있으면 브라우저 알림 (누르면 해당 메시지로 이동) |
| 정리 | 메시지 스레드, 내가 볼 수 있는 대화 안에서만 검색 |
| 관리 | 관리자·일반 사용자 역할, 멤버 제거, 관리 작업 기록 |
| 조직 | **부서 채널** — 소속한 팀·본부·사업부 대화방에 자동으로 들어감. **조직도**(`/org`) — 왼쪽 다이어그램 + 오른쪽 계층 목록, 전 조직과 조직장·직급·인원, 이름을 누르면 프로필 카드 |
| 일정 | **캘린더·회의 예약** — 참석자를 초대하고 회의실을 예약(겹치는 예약은 막힘), 초대·변경·취소·시작 10분 전 알림 |
| AI | 대화 요약(원문 링크 포함), 할 일 추출(담당자·기한이 없으면 "미정") |
| 재미 | **말투 변환** — "ㅎㅇ"를 신하 모드로 바꾸면 "성은이 망극하옵니다". 미리 보고 승인해야 전송 |

## 이렇게 씁니다

1. A 가 `#프로젝트` 채널에 질문을 올립니다.
2. B 가 스레드로 답하면서 `@A` 를 부릅니다.
3. A 가 다시 접속하면 알림이 와 있고, 누르면 그 답변으로 바로 이동합니다.
4. 밀린 대화는 **요약** 버튼으로 몇 줄에 확인하고, **할 일 뽑기**로 누가 무엇을 할지 정리합니다.

## 지금 되는 것

배포 URL 에서 아래가 모두 됩니다 (2026-09-30 운영 배포).

- 이메일로 가입·로그인·로그아웃. 로그인하지 않으면 채팅 화면에 들어갈 수 없음
- 가입하면 전사 채널 `#일반` 에 자동으로 들어감. 작성자는 로그인 정보로 정해짐 (닉네임으로 신원을 판단하지 않음)
- 채널 멤버만 대화를 읽고 쓸 수 있음. 멤버가 아니면 API 로 직접 요청해도 0건 (DB 권한 정책)
- 카카오톡처럼 메시지 옆에 **안 읽은 사람 수**. 상대가 읽으면 새로고침 없이 줄어듦. 탭을 열어 화면에 보인 메시지까지만 읽은 것으로 침
- **알림**: DM·나를 부른 멘션·내 스레드의 답글이 오면 알림 목록과 배지, 화면을 보고 있으면 오른쪽 아래 토스트, 다른 탭이면 브라우저 알림 ("알림 켜기"로 허용). 탭 제목에 `(안 읽은 수)`. 누르면 그 메시지로 이동하고, 채널이나 스레드를 열어 그 메시지가 화면에 보여도 읽음이 됨
- **AI 할 일**: 헤더의 "할 일" → 대화에서 할 일·담당자·기한을 제안 (대화에 없으면 "미정"). "저장"을 눌러야 남고, 완료 표시·삭제
- **채널 정보**: 헤더의 "채널 정보" → 멤버 목록. 관리자는 멤버 내보내기와 관리 기록을 봄
- **채널 초대**: 채널을 만든 사람과 초대 권한을 받은 멤버가 "채널 정보"에서 비공개 채널에 사람을 넣고, 다른 멤버에게 초대 권한을 줌. 권한 빼기와 내보내기는 관리자만 (2026-09-29 `develop`, 운영 배포는 다음 `main` 머지 때)
- **일정 알림**: 회의에 초대되거나, 회의가 바뀌거나 취소되거나, 시작 10분 전이면 알림. 내가 만든 회의에 누가 불참하면 "회의 불참" 알림. 누르면 그 회의로 이동
- **AI 요약**: 헤더의 "요약" → 안 읽은 것 또는 최근 50건을 몇 줄로. 항목마다 "원문" 링크 (서버에 `OPENAI_API_KEY` 가 있어야 동작)
- **스레드**: 메시지에 답글을 달면 오른쪽 패널에 모이고, 본문에는 "답글 N개"만 보임 (새로고침 없이 늘어남)
- `@` 를 치면 채널 멤버 자동완성 (이름·부서·직급, 동명이인은 부서로 구분). 멤버를 부른 멘션만 강조. 멘션은 어디서나 **이름**으로 보임 — 채팅·스레드·알림·검색·AI 요약 (2026-09-29). `@모두`(이 채널 전체)·`@부서명`(그 부서와 하위 부서 가운데 이 채널 멤버)도 부를 수 있음 (2026-09-30)
- **말투 변환**: 입력창 왼쪽의 말투 버튼(말풍선·반짝이 아이콘)으로 신하·선비·정중 말투 미리보기 → 승인해야 전송 (서버에 `OPENAI_API_KEY` 가 있어야 동작)
- 파일 첨부: PNG·JPEG·PDF 5MB 이하. 이미지는 미리보기, PDF 는 내려받기. 확장자만 바꾼 파일은 서버가 파일 내용을 보고 거부. 대화 멤버가 아니면 파일 주소를 알아도 못 엶
- 메시지 보내기·받기 (새로고침 없이 즉시), 작성자·시각 표시, 빈 메시지 차단
- 대화가 DB 에 저장되어 새로고침·재접속해도 남음
- 연결 상태(연결됨·재연결 중·끊김)와 접속자 수 표시, 전송 실패 시 "다시 보내기"
- 끊겼다 다시 연결되면 놓친 메시지만 받아 옴
- 처음엔 최근 50건만 불러오고, 위로 올리면 이전 대화가 이어 붙음 (보던 자리는 그대로)
- 메시지 속 `http`·`https` 주소는 링크로, `@이름` 멘션은 강조로 보임 (나를 부르면 더 눈에 띄게). HTML·스크립트는 글자 그대로 보이고 실행되지 않음
- 주소 `/chat?m=<메시지 번호>` 로 그 메시지로 이동해 잠깐 강조 (알림·검색·요약이 이 방식으로 이동)
- 채널 만들기(공개·비공개), 공개 채널 찾아 참여하기, 채널 바꾸기. 휴대폰 폭에서는 위쪽 채널 이름을 누르면 채널 목록이 열림
- 1:1 DM — "새 메시지"에서 이름·부서로 사람을 찾아 대화 시작 (같은 사람과는 늘 같은 방). 누가 나에게 DM 을 보내면 목록에 바로 뜸
- 채널·DM 목록에 안 읽은 메시지 수 배지 (새로고침 없이 늘고, 읽으면 사라짐, 재접속해도 유지)
- 헤더 검색창 — 두 글자부터 내가 멤버인 대화에서 한글 부분 단어로 찾고, 결과를 누르면 그 메시지로 이동 ("이 대화에서만" 선택 가능)
- **화면 개편** (2026-09-30):
  - 로그인하면 **대시보드**(`/`): 오늘의 일정·안 읽은 메시지·내 회의실 예약·새 알림 카드, 오늘의 일정 목록, 빠른 실행(새 메시지·일정 추가·회의실 예약), 오늘 할 일(내가 담당인 것, 체크하면 끝냄), 회의실 사용현황, 최근 대화
  - **조직도** 페이지(`/org`): 왼쪽 큰 다이어그램(회사·사업부·본부·팀을 색으로 나누고 직각 선으로 이음, 조직장·인원, 고른 조직까지 한 줄로 강조, 확대·축소·끌어서 이동)과 오른쪽 계층 목록(조직 아래 사람·직급·직책, 누르면 프로필 카드). 한쪽에서 고르면 다른 쪽도 따라감. 가운데 손잡이를 끌어 폭 조절, 목록 칸 접기·펼치기. 이름·직급·부서로 찾기. 채널 정보 멤버에는 이름 · 팀 · 직급
  - 모든 화면 왼쪽에 메뉴(홈·메시지·일정·회의실 예약·알림·조직도·설정·내 카드), 위에 검색·알림·내 메뉴. 휴대폰 폭에서는 메뉴가 아래 탭 막대
  - 채팅은 `/chat`: 메시지 목록 칸(검색·즐겨찾기·채널·DM) + 대화 + 채널 정보(설명·멤버 사진·고정된 메시지·채널 설정). `#일반` 은 목록에 보이지 않음 (채널은 그대로)
  - 이름이나 사진을 누르면 **프로필 카드**(소속·상태·공개한 연락처·상태 메시지, "메시지"·"일정 잡기")
  - **내 프로필**(설정): [사진 바꾸기] 하나(사진 올리기·캐릭터), 현재 상태(버튼 3개, 누르면 바로 적용)·상태 메시지([저장]·Enter, 비우고 저장하면 지움), 기본 정보(글자로만, 고칠 수 없음) 맨 아래 연락처만 [수정] → [저장]·공개·비공개, 계정 관리(아이디·비밀번호 변경·로그아웃). 전체 저장 버튼 없이 부분마다 저장 (2026-09-30 사용자와 다시 정함)
  - 메시지에 마우스를 올리면 리액션·답글·고정, 채널 즐겨찾기(별), 채널 이름·설명 수정(만든 사람·관리자), 채널별 알림 끄기 — **2026-09-30 원격 DB 적용**
- **채널 헤더** — "총인원 45명 · 접속 4명 ●2 ●1 ●1" 처럼 이 채널 멤버 수와 지금 접속한 사람 수(상태별 색). 연결이 흔들리면 "재연결 중…"·"끊김" 알약이 뜸 (2026-09-30 `develop`)
- **사진·상태 점** — 채팅·스레드 메시지 왼쪽, 조직도, DM 목록, 사람 찾기 결과에 프로필 사진과 상태 점(초록 온라인·노랑 자리 비움·빨강 방해 금지·회색 오프라인). 남이 상태를 바꾸면 새로고침 없이 바뀌고, 점에 마우스를 올리면 상태 메시지도 보임. DM 을 열면 헤더에 "@이름 ● 상태 · 상태 메시지" (DM 에서는 연결이 끊겼을 때만 연결 상태가 보임). "오프라인으로 표시"를 고르면 남에게는 오프라인으로 보이고 접속자 수에서도 빠짐. 남의 상태는 API 로도 읽을 수 없음 (2026-09-30 운영 배포)
- **내 프로필** — 헤더의 내 이름을 누르면 상태(온라인·자리 비움·방해 금지·오프라인으로 표시)를 바로 바꾸고, "내 프로필"을 열어 프로필 사진(사진 올리기 또는 캐릭터 12종)·상태 메시지·연락처(공개·비공개)·비밀번호를 바꿈. 이름·부서·직급·이메일은 인사 정보라 보기만 함 (DB 가 본인 수정을 막음) (2026-09-30 운영 배포)
- 라이트·다크 테마 — 헤더·캘린더·로그인 화면의 해·달 스위치에서 원하는 쪽을 누름. 처음에는 컴퓨터 설정을 따르고, 고르면 그 브라우저에 기억됨 (새로고침해도 깜빡이지 않음)
- `/calendar` 주간 캘린더 — 회의 만들기·고치기·취소, 참석자 초대(이름·부서로 찾기), 참석·불참 응답, 회의실 3개 예약 현황(남의 회의는 시간대만). 같은 회의실을 겹치게 잡으면 DB 가 막음 (동시에 눌러도 하나만)

**아직 안 되는 것**: 계획한 기능(PRD Step 1~5·캘린더)은 배포 URL 에 모두 들어 있습니다 (검색 포함, 2026-09-29 배포 URL 에서 확인).
추가로 만든 **조직도·부서 채널**도 운영에 들어갔습니다 (2026-09-29 18:13 배포, PR #20). 운영 DB 에는 가상 회사 "한결테크 주식회사" 데이터가 있습니다.
회사 계정으로 로그인한 사람은 자기 팀·본부·사업부 채널에 들어가 있고(나갈 수 없음, 채널 목록에서 `#일반` → 사업부 → 본부 → 팀 순), 헤더의 "조직도"로 그 부서의 조직도를 보고 사람을 눌러 DM 을 엽니다.

## 로컬 실행

Node.js 20 이상과, Vercel 프로젝트(`office-chat`)에 접근할 수 있는 Vercel 계정이 필요합니다.
DB 는 원격 Supabase 를 함께 씁니다.

```powershell
npm install
```

DB 접속 정보를 `.env.local` 로 받아 옵니다 (처음 한 번, 저장소에는 올라가지 않음).

```powershell
npx vercel link --project office-chat
```

```powershell
npx vercel env pull .env.local
```

```powershell
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 창 두 개(또는 일반 창 + 시크릿 창)로 들어가면 서로 대화할 수 있습니다.

원격 DB 에 자동 검사를 돌릴 수 있습니다. 검사가 만든 메시지·가상 사용자는 끝나면 지워집니다.

```powershell
npm run check:step1
```

```powershell
npm run check:db
```

```powershell
npm run check:attach
```

1만 건 채널로 페이지네이션·검색 속도를 재려면 `npm run seed:10k` → `npm run seed:10k -- --measure`, 다 쓰면 `npm run seed:10k -- --delete` (공유 DB 라 꼭 지웁니다).

회사 데이터는 스크립트로 넣습니다 (운영 DB 에도 이것을 씁니다). `.env.local` 에 `SEED_PASSWORD=<6자 이상>` 을 넣고 실행하면
가상 회사 "한결테크 주식회사"(사업부 2 · 본부 5 · 팀 10)의 직원 37명, 부서 채널, 프로젝트 채널 2개, 샘플 대화, 샘플 회의가 생깁니다.
계정은 `<handle>@example.com` 이고(명단은 `scripts/seed-company.mjs`), 모두 같은 비밀번호로 로그인합니다.
운영 DB 의 37명 비밀번호는 팀원끼리 따로 전달하고 `.env.local` 의 `SEED_PASSWORD` 에 적어 둡니다 (저장소에는 쓰지 않습니다).
예: 백엔드팀 사원 이서연 `sylee@example.com`. 가입 확인 메일 없이 바로 로그인할 수 있고, 여러 번 돌려도 됩니다.
시드는 자기가 만들지 않은 계정은 건드리지 않습니다. 운영 DB 에는 시드 직원 37명과 관리자 2명(김송이·이호섭 계정)만 있습니다 (2026-09-30 정리).
