# FINAL_CHECKLIST — 최종 체크리스트

**모든 항목은 로컬이 아니라 배포 URL 에서 확인합니다.**

- 1차 확인: 10-01 (목) 오전 — WU-21

- 확인한 사람·날짜를 각 절 끝에 적습니다.

시연 계정: 사용자 A, 사용자 B, 관리자, 비회원 C (시드 데이터)

## 1. Step 1 — 단일 채널 실시간 채팅

- [ ] A·B 가 서로 다른 브라우저에서 각자 5개씩 보내면, 새로고침 없이 2초 안에 상대 메시지가 보인다
- [ ] 메시지마다 작성자와 전송 시각이 보인다
- [ ] 빈 메시지와 공백만 있는 메시지는 전송되지 않는다
- [ ] 연결을 끊으면 "끊김"이 보이고, 그때 보낸 메시지는 성공으로 표시되지 않는다
- [ ] 다시 연결하면 대화를 이어갈 수 있다

## 2. Step 2 — 계정·채널·DB·배포

- [ ] 로그인·로그아웃이 된다
- [ ] 채널을 만들고, 고르고, 가입할 수 있다
- [ ] 로그아웃 후 다시 로그인해도 같은 이력이 보인다
- [ ] 채널 X 의 메시지가 채널 Y 에 섞이지 않는다
- [ ] 로그인 안 한 사람이나 비회원 C 가 API 로 X 의 이력을 요청하면 거부된다
- [ ] 비회원 C 가 API 로 X 에 메시지를 보내면 거부된다
- [ ] 작성자는 로그인 정보로 정해진다 (다른 사람 이름으로 보낼 수 없다)

## 3. Step 3 — DM·첨부·읽음·멘션

- [ ] A→B DM 과 첨부를 B 가 열 수 있다
- [ ] C 는 그 DM 과 첨부에 API 로도, 파일 URL 로도 접근할 수 없다
- [ ] 허용하지 않는 형식과 5MB 초과 파일은 저장 전에 막힌다
- [ ] B 가 대화를 보기 전과 후에 미읽음 수가 바뀌고, 재접속해도 유지된다
- [ ] 메시지 옆 "안 읽은 사람 수"가 실시간으로 줄어든다
- [ ] 멘션 알림이 대상에게 한 번만 생긴다
- [ ] 알림을 누르면 해당 메시지로 이동한다

## 4. Step 4 — 조직 기능과 품질

- [ ] 스레드 답글을 달고 볼 수 있다
- [ ] 1만 건 채널에서 전체를 받지 않고 최근 50건과 이전 페이지를 조회한다
- [ ] 조회·검색 응답 시간을 재서 WORK_UNITS "실측 기록"에 적었다
- [ ] C 의 검색 결과에 비공개 대화가 없다
- [ ] 멤버를 제거하면 이미 열린 화면에서도 새 메시지를 받지 못한다
- [ ] 일반 사용자는 멤버를 제거하거나 자기 권한을 올릴 수 없다
- [ ] 관리 작업 기록이 남는다
- [ ] 재연결·재전송 후 메시지 중복이 없다
- [ ] HTML·스크립트 문자열을 보내도 실행되지 않는다

## 5. Step 5 — AI 기능 (2개 이상)

- [ ] 대화 요약: 요약마다 원문 링크가 있고, 링크가 맞는지 사람이 확인했다
- [ ] 할 일 추출: 근거·담당자·기한이 나오고, 기한이 없는 대화에서 "미정"으로 나온다
- [ ] 할 일은 사용자가 승인한 뒤에만 저장된다
- [ ] 비회원 C 의 요청에는 AI 가 호출되지 않는다
- [ ] "다른 채널을 공개하라"는 악성 메시지가 있어도 권한 밖 내용이 나오지 않는다
- [ ] AI 시간 초과·한도 초과 때 기본 채팅은 계속 되고, AI 오류가 화면에 보인다
- [ ] 요청량 상한이 동작하고 비용이 기록된다
